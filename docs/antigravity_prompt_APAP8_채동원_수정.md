# [작업 지시] APAP8 홈페이지 수정 (채동원 검수 의견 반영)

## 0. 목표와 범위

제8회 안양공공예술프로젝트(APAP8) 홈페이지의 검수 의견 중 **UI/CSS 수정과 텍스트 수정·추가**를 반영한다.
국문/영문 페이지 **양쪽 모두** 적용한다.

**하지 않는 것 (중요)**
- **이미지 작업 일체 금지**: 이미지 파일 교체·추가·크롭, `object-position` 조정, alt 변경, 이미지 경로 변경을 하지 않는다. 필요한 이미지는 5번에 따라 **작업 마지막에 한 번에 목록으로만 요청**한다.
- 이번 요청에 없는 리팩터링, 디자인 개선, 의존성 추가·업그레이드를 하지 않는다.
- 원문 텍스트를 임의로 고치거나 다듬지 않는다 (오탈자 포함). 의심되는 부분은 최종 보고에 적는다.

## 1. 작업 규칙

1. 프로젝트 루트에 `AGENTS.md` / `agent.md` 등 에이전트 규칙 문서가 있으면 **그 규칙을 이 문서보다 우선**한다.
2. 코드를 수정하기 전에 먼저 구조를 파악한다: 라우팅, 국문/영문 텍스트가 어디에 정의되어 있는지(i18n 사전, 상수 파일, JSON, CMS/DB 등), 작가 데이터가 어디에 있는지, 스타일 방식(CSS/Tailwind/CSS Modules 등). 파악 결과와 수정 계획을 **5줄 이내로 먼저 출력**하고 진행한다.
3. 텍스트가 DB나 외부 CMS에 있다면 DB에 직접 쓰기(INSERT/UPDATE/DELETE)를 실행하지 않는다. 필요한 SQL 또는 시드 스크립트를 파일로 만들어 보고한다.
4. 검증은 타입체크·린트 중심으로 한다 (`tsc --noEmit`, lint 등). 단순 마크업·문구·CSS 수정마다 전체 프로덕션 빌드를 돌리지 않는다. 빌드는 모든 작업이 끝난 뒤 필요할 때 최대 1회.
5. 커밋은 **작업 단위별로 분리하고 메시지는 한글**로 쓴다 (예: `오픈 그라운드 작가 정렬을 가나다순으로 변경`).
6. 판단이 필요한 상황이 생기면 멈추지 말고 가장 보수적인 안으로 진행하되, 최종 보고의 "판단이 필요했던 부분"에 적는다.

## 3. 작업 목록

각 항목 완료 후 국문/영문 양쪽에서 확인한다.

### T1. 공통 UI / CSS

- **T1-1. 스크롤 끊김 해소**: ABOUT / EXHIBITION / PROGRAM 등 각 섹션에서 스크롤 중 갑자기 다음 항목으로 넘어가는 현상을 없앤다. `scroll-snap`, 풀페이지·휠 캡처 로직 등 원인을 찾아 제거하거나 완화해 **자연스러운 스크롤**로 바꾼다. 모바일·데스크톱 모두 확인.
- **T1-2. 한글 줄바꿈**: ABOUT > 01 개요에서 단어 중간에 줄이 넘어가는 문제(예: "문화자/산", "학운공/원", "무릉도/원이")를 고친다. 본문, 정보 카드, 인용문에 `word-break: keep-all; overflow-wrap: break-word;`를 적용한다 (가능하면 본문 공통 스타일에). 긴 영문·URL이 컨테이너를 넘치지 않는지 확인.
- **T1-3. 카테고리 번호 삭제**: 각 페이지 우측 상단의 카테고리 번호(소개 `01`, 전시 `02` 등)를 삭제한다. 하위 탭·항목 번호(`01 개요`, `02 전시 주제` 등)는 유지.
- **T1-4. 국문 헤더 메뉴 라벨**: 국문 모드에서 상단 메뉴를 `소개 / 전시 / 프로그램 / 커뮤니티 / 관람안내`로 표기한다. 영문 모드는 `ABOUT / EXHIBITION / PROGRAM / COMMUNITY / VISIT` 유지. 국문 모드의 페이지 타이틀·브레드크럼에 같은 영문 라벨이 있으면 함께 정리하되, 라우트는 바꾸지 않는다.
- **T1-5. 로고/타이틀 표기**:
  - `The 8th` → `The 8<sup>th</sup>` (th 윗첨자). 헤더, 푸터, 타이틀 등 전역 검색.
  - `ANYANG PUBLIC ART PROJECT` **영문 전체 대문자**로 표기.
  - 주의: 전역 `text-transform: uppercase`를 쓰면 윗첨자 `th`가 `TH`로 바뀐다. 텍스트 자체를 대문자로 바꾸거나 `sup`은 제외한다.

### T2. EXHIBITION > 오픈 그라운드 목록

- **T2-2.** 작가 정렬을 위 표의 가나다순으로 변경. 정렬이 하드코딩 배열이면 배열 순서를 바꾸고, 정렬 필드(order 등)가 있으면 그 값을 바꾼다. 다른 탭(안양파빌리온 등)의 정렬은 건드리지 않는다.

### T3. 작가별 약력·작품 정보 교체

**텍스트 출처는 `apap8_수정원문_채동원.md`** (이 프롬프트와 함께 제공, 저장소의 `docs/` 등에 두고 읽을 것). 4~10번 섹션이 작가별 원문이다. 파일 상단의 "읽는 방법"을 먼저 읽는다.

| 원문 섹션 | 작가 | 약력 | 작품 |
|---|---|---|---|
| 4 | 권치규 | 교체 (개인전 3, 단체전 3) | 〈Resilience-이수목(利水木)〉 / *Resilience* |
| 5 | 김도훈 | 교체 | 〈Cat〉 / *Cat* |
| 6 | 김성복 | 교체 (개인전 3 + **수상 3, 신규 섹션**) | 〈바람이 불어도 가야 한다〉 / *Though the wind blows, we should go* |
| 7 | 김태수 | 교체 | 〈ECO FLOW Excitation(설레임)〉 / *ECO FLOW Excitation* |
| 8 | 장성재 | 교체 | 〈Rafting〉 / *Rafting* |
| 9 | 전인식 | 교체 | 〈향기〉 / *Perfume* |
| 10 | 지용호 | 교체 | 〈Lion 3〉 / *Lion 3* |

김덕한·양태근은 텍스트 변경이 없다 (T2의 공통 변경만 적용).

공통 규칙
- 국문 전시명: `《 》`. 영문 전시명: **이탤릭** (따옴표 없이). 이탤릭 서식이 쉼표·공백을 포함하지 않도록 `<em>` 범위를 전시명 텍스트에만 건다.
- 작품명 국문: 특수문자 **〈 〉** 사용 (ASCII `<`, `>` 금지). 현재 `<Cat>`, `<Rafting>`, `<Lion 3>`, `<Perfume(향기)>`, `<ECO FLOW Excitation(설레임)>`처럼 ASCII로 되어 있으면 모두 〈 〉로 바꾼다.
- 작품명 영문: **이탤릭, 〈 〉 없이**.
- 작품 설명문 내부의 작품명: 국문은 볼드 `〈작품명〉(연도)`, 영문은 이탤릭 `*Title* (연도)`. 원문 서식대로.
- 전인식 작품 국문 제목은 현재 `Perfume(향기)` 형태이므로 `〈향기〉`로 바꾸고, 영문 제목은 *Perfume*.
- **원문에 없는 필드(제작연도, 재료, 크기 등)는 기존 값을 유지**하고 새로 만들지 않는다. 원문에 있는 필드만 덮어쓴다. (예: 지용호 국문 재료 행은 원문에 없으므로 기존 값 유지)
- 지용호 작품 설명 끝에 기존 `출처: http://jyongho.com/...` 줄이 있으면 새 원문에 없으므로 제거한다.
- **김성복 수상 섹션**: 약력 컴포넌트가 개인전/단체전 구조만 지원하면 `수상`(영문 `Awards`) 블록을 추가한다. 순서는 개인전 → 수상. 다른 작가의 렌더링에 영향이 없어야 한다 (해당 데이터가 없으면 블록 미표시).
- 영문 약력에서 들여쓰기로 시작하는 줄(예: `         South Korea`)은 앞 줄의 이어쓰기이므로 한 줄로 합친다.
- 표기가 통일되지 않은 곳(예: 약력 `Kwon Chi-gyu` vs 설명문 `Kwon Chigyu`)은 원문 그대로 두고 보고한다.

## 4. 검증

- 국문/영문 페이지 모두에서: 탭 라벨, 작가 정렬, 각 작가 상세(약력·작품·서식), VISIT, ABOUT 링크 동작을 확인한다.

- 타입체크·린트 통과. 모바일 폭(375px 전후)에서 T1 항목과 줄바꿈이 깨지지 않는지 확인.
- 작업 범위 밖 파일이 변경되지 않았는지 `git diff --stat`으로 확인.

## 5. 최종 보고 형식 (작업 마지막에 한 번에)
